# Working in this workspace

This is the owner's workspace.
Rouh's agent instructions, which the owner edits on the Agent instructions page, say how to work here, and they are given to every job when it starts.

- Each task has an `AGENTS.md` at the root of its folder, with where it stands first.
- A task's status and summary are in Rouh's database; change them with `bin/task`.
- Put throwaway files in a step's `temp/` folder.
- Never read, print or ask for a secret.
