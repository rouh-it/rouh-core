{% if company == "anthropic" %}
  1. Make an account. Open the Claude Console and press Continue with Google, or type your email.
    Open the Console
  2. Buy $20 of credit. Settings → Billing → Buy credits → 20.
  3. Turn on auto reload. On the same page: Set up auto-reload. When the balance reaches $5, bring it back up to $20. Press Turn on.
  4. Set a monthly limit. Settings → Workspaces → Create workspace, name it "Rouh". Open it → Spend limits → Monthly limit $50. Keys in that workspace can never spend more than this in a month.
  5. Make the key. Settings → API keys → Create key. Name: {{ name }}. Workspace: Rouh.
  6. Copy it now. It starts with sk-ant- and is shown only once. Paste it in the box.
{% else %}

    Open the Platform
  2. Buy $20 of credit. Settings → Billing → Add to credit balance → 20.
  3. Turn on auto recharge. When the balance falls below $5, recharge it to $20. Set the monthly recharge limit to $50.
  4. Make the key. Settings → API keys → Create new secret key. Name: {{ name }}.
  5. Copy it now. It starts with sk- and is shown only once. Paste it in the box.
