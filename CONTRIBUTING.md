# Contributing to Rouh

Thank you for helping. Rouh is open source under the Apache License,
Version 2.0 (see `LICENSE`). Rouh's code is being assigned to TwoGears
EOOD (see `NOTICE`), and is planned to move to a non-profit Rouh
Foundation later.

## Sign off every commit (the DCO)

We do not ask you to sign a contributor agreement. Instead, every
commit must carry a sign-off line, by which you certify the
Developer Certificate of Origin 1.1 (the `DCO` file in this
repository, also at https://developercertificate.org/):

    Signed-off-by: Your Name <your.email@example.com>

Git adds it for you with `git commit -s`. Use your real name (or the
name you are publicly known by) and an email address that reaches you.
A pull request whose commits are not all signed off cannot be merged;
an automatic check says which ones are missing it.

By signing off you confirm that you wrote the change or have the right
to submit it under the Apache License 2.0. Your contribution is then
licensed under the Apache License 2.0, as section 5 of that licence
says. You keep the copyright in what you wrote; you do not give it to
TwoGears or anyone else.

## Code written with AI tools

You may use AI tools. You are responsible for what you submit: read
it, test it, and make sure it does not copy code whose licence does
not allow it. If a large part of a change was generated, say so in
the pull request.

## Copyright lines in files

Do not add your own copyright header to a file. The project's rule is
in `COPYRIGHT-HEADERS.md`: new files get the short SPDX line, and the
git history records who wrote what.

## The name

"Rouh" is a trade mark of TwoGears EOOD. You may say your fork or
product "is based on Rouh" or "works with Rouh", but do not call it
Rouh or use Rouh's logo for it.

## Security

Do not report security problems in public issues. See `SECURITY.md`.
